# 🧪 Testes-Manuais - SIFIT

Repositório do projeto de extensão da disciplina de Qualidade de Software, com a documentação dos testes manuais do sistema SIFIT (sistema para academias), com foco em:

- Aprendizado de QA
- Organização de casos de teste
- Melhoria contínua na análise e cobertura de testes

## 🎯 Objetivo

Este projeto foi criado com o objetivo de:

- Aplicar os conhecimentos de testes manuais em um sistema real
- Encontrar e relatar problemas de usabilidade, funcionamento e segurança
- Sugerir melhorias para a empresa responsável pelo sistema

## 🧱 Estrutura do repositório

A estrutura está organizada por pastas, cada uma representando um sistema/teste diferente:

📁 **SIFIT** ↳ Análise de Requisitos, Plano de Testes, Cenários, Relatórios de Bug e Evidências

## 🧪 Metodologia

- **Técnicas aplicadas:** Testes Positivos, Negativos, Exploratório, Funcional
- **Ferramentas:** Markdown, GitHub, Jam, MySQL Workbench
- **Formatos:** BDD (Gherkin), Tabelas e Checklist
- **Processos:** Planejamento de Teste, Execução e Relatório
